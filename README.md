# MediQueue — Clinic Appointment Scheduler
**Domain:** Healthcare | **Stack:** Flutter, Dart, Material 3

Features:
- Appointment dashboard and confirmed-visit summary
- Book appointment with patient name, specialty, doctor and time slot
- Input validation and booking feedback
- Responsive appointment cards and status indicators

Run:
```bash
flutter pub get
flutter run
```
Demo only: appointments are held in memory; no real clinic system or backend is connected.

Resume description (after testing):
- Developed a Flutter mobile appointment scheduler with validated booking forms and selectable doctor/time options.
- Created reusable schedule cards and appointment status indicators.
